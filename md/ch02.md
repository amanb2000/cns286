Using machines to learn predictive models turns out to work better for a lot of problems than trying to hand-derive or hand-calculate the solutions. 
By using lots of data to infer parameters for the right class of model, you can solve a lot of problems. 
Moreover, machine learning lets us get past some of the scaling issues associated with the **combinatorial explosion** we discussed before -- where the number of $k$-character sequences of lowercase English is $26^k$. 
Assigning probabilities over such a large sample space is tough without a little help from some **learning machines**. 

In this chapter, we will grow your understanding of parameter estimation from [Chapter 1](ch01.html) to include modern computational methods and concepts, from statistical learning to machine learning to deep learning. 
There are several key mathematical concepts that I also hope to unify in your mind: 

 1. Parameter estimation
 2. Learning algorithms
 3. Projection
 4. Function approximation
 5. Optimization

After this chapter, you will be able to soup up your N-gram language model to use some fancier statistical learning and deep learning methods to factorize the combinatorially exploding sequence space and aggregate context over longer sequences with better accuracy. 
Since it's a bit of a mouthfull to get through all of statistical learning, machine learning, deep learning, AND all the ways we've figured out to do sequence modelling, I'll just focus on the first 3 and save the last one for [Chapter 3](ch03.html)
